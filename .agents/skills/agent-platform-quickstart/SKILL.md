# Agent Platform Quickstart Skill

1. Run `npm test` to verify all 29 package suites (`155` tests).
2. Run `npm run tutorials` to execute all 5 end-to-end tutorials (`01`–`05`).
3. Run `npm run build:dashboards` to regenerate static dashboards in `dashboards/`.
